左侧导航首项为“外观”，常规设置入口默认进入该页。应用主题的 fit Select 使用共享内容自适应弹层并与 trigger 右对齐，不在业务面板写固定宽度。编辑器主题的配置、预览和持久化能力完整保留，当前默认使用“落笔”并暂时隐藏用户选择区。

专注模式、打字机模式与 Markdown 预览是高频视图状态，不在“写作 → 编辑器”中作为持久化设置展示；打字机模式的用户入口归原生“视图”菜单。

写作设置的“编辑器”分组承载默认关闭的“保存时进行中文排版优化”，因为它控制用户主动 `⌘S` 的编辑器行为；独立的“Markdown 中文排版优化”分组只定义五项具体排版规则。自动保存不得隐式触发排版或历史版本。

“图片引用”与“字体”选择器的 trigger 按当前选项内容自适应，弹层继续使用共享 Select 的 `fit` 内容宽度并与按钮右对齐；不得用业务级 `max-width` 或固定 content 宽度截断较长选项。

设置界面只编辑各领域公开配置，不复制领域校验和持久化实现。“本地文件”区分“在文件管理器中显示”、迁移当前目录与打开已有写作文件夹；切换入口只负责收集用户选择，目录结构校验和保存后切换归 library 领域。该区域还提供带确认的重建索引入口，并用不可中断的阶段进度弹窗承接运行状态、用全局 Toast 报告成功或失败；扫描、旧文稿 ID 迁移和引用修复仍完全归 native library 领域。GitHub 等跨项目身份归全局“发布”设置，通过官方 Device Flow 一次连接并由 native secret store 持有令牌；GitHub 博客等非敏感发布目标同样归应用级“发布”设置，以 provider 下的独立子项编辑仓库、分支、目录、站点和菜单名称。持久化单选设置统一使用共享 Select；Tabs 只切换当前内容视图，Toggle Group 只保留给高频即时操作，不再维护设置专用分段选择器。设置内容页的分组小标题统一使用 `SettingsSectionHeader`：14px 主文字色，可选说明使用 12px 次级文字色且没有说明时不预留空白。设置 Dialog 的主体、侧栏、区块与分区边界统一消费 `index.css` 中的专属语义 Token：主体跟随应用 `background`，侧栏复用 Tabs 容器的 `muted` 灰色；设置区块在亮色模式融入 `background`，在暗色模式使用 `muted` 建立层级。敏感值必须交给 native secret store，不能在表单组件中建立第二套存储。

AI 助手展示形态不在设置 Dialog 维护；其唯一持久入口是助手自身更多菜单中的“固定到侧边”。AI 设置首个“默认”分组统一选择已添加的对话连接、该连接模型目录中的默认模型、模型明确支持的思考强度、由已添加连接能力派生的图片服务与发送快捷键；连接变化后模型、思考和生图选项必须同步收敛，不能展示跨 Provider 的陈旧能力。连接区以列表展示真实存在的 OAuth 授权和已配置 API 凭证，并在右侧以带说明的轻量图标展示已接入的文本、思考和图片能力，但不得展示 ChatGPT 邮箱等账号标识，默认项排在首位；左下角单一“添加连接”菜单分流 ChatGPT 订阅与其他提供商。ChatGPT 复用可取消的 Device OAuth 弹窗，关闭弹窗或主动取消必须终止原生轮询；不同 Provider 的状态读取必须相互隔离，单项失败不得清空其他连接。API 配置只列出已经接入的 OpenAI、Anthropic、千问、MiniMax、DeepSeek、Kimi 与自定义服务商；固定 Provider 切换时必须同步显示只读官方 Endpoint，自定义 OpenAI Responses 服务才允许编辑 HTTPS 根地址。API Key 眼睛按钮只切换当前未提交草稿的可见性，保存后仍不得从 native 读回明文；重新认证、替换凭证、验证和删除统一收进连接行的更多菜单。API 连接验证由 native 使用 Provider 模型目录执行无生成探测，不把明文凭证或响应目录带回 renderer。快捷提示与 Skills 在 AI 设置主页只提供说明、数量与进入入口；各自的完整列表和管理动作接管同一内容区的二级页面，并由页内返回按钮恢复 AI 设置主页，不得为这层导航再叠加一个列表 Dialog。快捷提示二级页维护新建、排序、编辑和删除；Skills 二级页只调用 native Skill Store 完成当前写作库 Skill 的导入、诊断、启停、删除与目录打开，不复制文件校验；目录和归档包只是导入来源，统一收在一个“导入”菜单中。联网搜索由 native runtime 按当前对话连接自动路由原生搜索或 DuckDuckGo，设置页不得再要求独立搜索 API Key。MCP 底层 client、凭证与工具执行边界暂时保留，但 AI 设置页不展示 MCP server 配置；未来以“外部资料来源”产品化后再接回可见入口。图片服务只显示已添加且明确声明图片能力的连接，允许自动优先复用当前对话 Provider，也允许固定到另一个可生图连接，因此文本回答可使用 OpenAI-compatible 服务而生图固定使用 ChatGPT。图片 API Key 不得拥有独立入口，必须通过连接管理添加；界面不得暗示 GPT 文本模型本身直接输出图片。敏感表单只持有未提交草稿，OAuth 界面只接收设备码和无账号标识的订阅状态，保存后不得从 native 读回明文。

设置页中的品牌 SVG 只用于连接管理语境：已添加连接列表、添加连接菜单和 API 服务商选择列表复用 assistant 的 Lobe SVG 适配器，保持 `1em` 文字尺寸同步；默认连接/模型/生图选择与 OAuth 内部操作不显示品牌图标。主助手 composer 的当前对话选择器拥有独立的紧凑图标例外，不改变设置页边界。OpenAI 与 Kimi 使用随主题前景色变化的官方单色版；自定义服务商使用中性 SVG，不冒用 OpenAI 品牌。添加连接菜单中已存在的单实例订阅项使用不可点状态和右侧圆圈对号表达，不重复打开旧管理弹窗；重新认证、验证与删除只从现有连接行的更多菜单进入。

快捷键浏览使用靠右、四周留白的近全高 Dialog，内容以单列分组和独立 keycap 呈现并支持即时搜索；该特殊定位只属于快捷键表面，不改变共享 Dialog 的居中默认值。
